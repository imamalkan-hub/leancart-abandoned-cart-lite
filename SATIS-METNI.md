## Long description
LeanCart Abandoned Cart Lite solves one daily problem for WooCommerce store owners: "being unable to track abandoned carts".
Instead of hundreds of options and bloated code, it is a focused tool that works
right after installation.

### Why buy it?
- **Saves time:** Recovers lost revenue by making abandoned carts visible
- **Minutes to set up:** Works with sensible defaults.
- **Secure:** WordPress CRUD API, nonce and capability checks, proper escaping.
- **Compatible:** WooCommerce 8+, HPOS, PHP 8.0+, WordPress 6.2+.
- **Supported:** 12 months of updates and support, 30-day money-back guarantee.

### Features
* Automatic cart capture (user meta, independent of object cache)
* Abandoned cart list
* Age filter (hours)
* Automatic cleanup on order or when the cart is emptied

Stores with high cart-abandonment rates
